## 📖 游戏简介

这是一款基于“点击消除”玩法的解谜小游戏。
玩家需要观察棋盘中箭头的方向，使用鼠标点击箭头。
- 如果箭头前方**没有**其他箭头阻挡，该箭头会成功飞出棋盘并消除。
- 如果前方**有**其他箭头阻挡，箭头无法飞出，并扣除 1 次失误次数（每关共 3 次失误机会）。
- 当清空棋盘上所有箭头时，即可通关当前关卡并进入下一关（共 5 个关卡）。
- 失误次数耗尽，则游戏失败。
